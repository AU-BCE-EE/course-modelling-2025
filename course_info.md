# Modeling course information
An introduction for students.

# Course overview
Mathematical and computer modeling (or modelling) is a fundamental part of virtually all modern research areas in science and engineering. 
In this course we will use a hands-on approach to introduce you to modeling for biological, chemical, and environmental engineering.
You will learn methods for developing models and implementing them using Python, the world's most popular programming language.

# Class organization
We expect that each class will be run something like this:

|                              |  Duration (min.)   |
|--------------                |-----------         |
| Discuss previous assignment  | 15                 |
| Warm-up problem              | 15                 |
| Lecture                      | 15                 |
| Break (9.00)                 | 15                 |
| Lecture                      | 20                 |
| Start new assignemnt         | 25                 |

You should be sure to bring a laptop with Python 3 installed to class.
But also bring a notebook and a pen or pencil to each class.

We will present some slides or notes in most classes, and will generally make some form of these materials available to students.
But these files of course cannot include everything we say or show, so you should expect to have an approach to take notes during class.

Active participation in class will help you learn, and it will generally make the class more effective for everyone.
Participation makes things easier for us, the instructors, as well, because your questions, answers, and comments help us guage your understanding and interest.
So please make an effort to engage in the topic and participate in class!

# Short assignments
The more modeling you do--the more effort you put into sketching out models, writing conservation and rate equations, writing Python code, and debugging models--the more you will learn in this course.
We will use regular assignments to help.
Assignments will typically be started in class, but you should expect to put in some time outside the classroom to complete them.
We plan to give you an opportunity to discuss each assignment in class and we will post solutions.

The main purpose of assignments is to give you a chance to work on modeling. 
Assignments will not be graded and they are not technically required for you to complete this course.
But they are an important part of the course and a wonderful opportunity for learning.
You should put in a real effort to complete them and always submit your work.

We will sometimes use your submissions to track student understanding and identify areas we need to explain more clearly.

Some assignments will be challenging, and abilities vary.
Working in a small group can be helpful.
Please keep the group size to no more than three students.

With or without a homework group, you should try to avoid copying and pasting Python code. 
You will learn and ultimately understand Python and modeling better if you type and debug code yourself.

# AI tools
ChatGPT and other artificial intelligence tools can be extremely good at writing Python code and much more besides.
We don't know what the future of education or work in science and engineering will look like in the coming years or decades, but AI will almost certainly drastically change both.
Please do not use AI for assignments.
We will discuss AI more in class, and look at some ways that it can be helpful.

# Git and GitHub
Git and GitHub are software tools used widely for developing and sharing software code and more.
This includes models--many teams rely on these tools to collaboratively create models that are then shared as software packages.

We will use Git and GitHub in this course.
That means all course files will be available through a GitHub repository, and you will submit assignments through GitHub.
One of your first assignments will include creation of a GitHub account.
