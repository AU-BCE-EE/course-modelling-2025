# Assignment 1. Getting started with GitHub

Complete all of the following tasks.

1. Check your official AU email inbox for a message from the GitHub au-bce-modeling-2025 organization, and accept the invitation inside for joining. 
   If you do not have an account associated with your AU address, create a new one. 
   When choosing a username, note that you will have to share it with instructors and classmates.
   Something derived from your name is probably best.
   For example, we use sashahafner and fdalby.
   Be sure to include your first and last names when entering your account information.

2. Log into <github.com> and check out the main course repository (repo) "home" here: <https://github.com/au-bce-modeling-2025/home>.
   Read the README.md file and `course_info.md`.
   This repo will be the main one for the course, so remember how to find it or bookmark it if needed.

3. Read through the GitHub introduction (`github_intro.md`) that you can find in the docs directory of the main course repo.
   Do try to browse to these file, but if you just cannot find it, you can use this link: <https://github.com/au-bce-modeling-2025/home/blob/main/docs/github_intro.md>.

4. Each GitHub repo has an "Issues" page for tracking repo issues.
   We will typically use these pages for issues (e.g., for you to tell us that a file is missing) and also discussions.
   Browse to the Issues page for this assignment01 directory by clicking on "Issues" near the top of the page:

<img width="1263" height="399" alt="image" src="https://github.com/user-attachments/assets/97034a61-40ad-4d38-b947-c420347fe723" />

   There should only be one issue present, and do what it says at the top.

5. Download this assignment01 repo, i.e., clone it.
   There are multiple ways to download files from GitHub. 
   Later we will probably encourage you to install some version of Git locally and clone the assignment repos, which will contain the question and a template for you to follow in your submission.
   But for this assignment, you can use the Green "Code" button and then select "Download ZIP".

<img width="1261" height="501" alt="image" src="https://github.com/user-attachments/assets/e051d7dd-759b-4c64-a238-b2cce5c50150" />

   Once downloaded, extract the files from the ZIP archive, and browse in and open up the local version of this Markdown file README.md with your text editor of choice.
