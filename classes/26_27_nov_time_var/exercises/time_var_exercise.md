# Time-variable inputs

Working with the wastewater lagoon polishing model (see module in this subdirectory), make the reaction rate constant time-variable.
Test your model by comparing OM predictions for the middle of the lagoon from the original with a constant rate and the a rate that varies 10x every 24 hours.

## Hints and tips
In the melting ice demo it was an input *variable* that we varied, while here it is a model *parameter*.
But the same concepts and programming applies.

If you have trouble seeing a difference, shorten the model run time and make sure you use a high resolution.
